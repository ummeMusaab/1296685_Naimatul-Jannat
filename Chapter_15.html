15.1 Color Names

CSS supports many predefined color names. These names can be used directly to apply colors to HTML elements.

Red red
Blue blue
Yellow yellow
Green green
Tomato tomato
Pink pink
Note: CSS color names are easy to remember and use. For example, the color name "tomato" represents a reddish color.

15.2 HEX Colors

HEX colors are written using a hexadecimal value that starts with a hash symbol (#). A HEX color contains six digits or letters: two for red, two for green, and two for blue.

Red #FF0000
Blue #0000FF
Lime #00FF00
Yellow #FFFF00
Purple #800080
Orange #FFA500

HEX Color Structure

HEX Value Color Description
#FF0000 Red Maximum red, no green or blue
#00FF00 Lime Maximum green, no red or blue
#0000FF Blue Maximum blue, no red or green
#000000 Black No red, green, or blue
#FFFFFF White Maximum red, green, and blue
Remember: In a HEX color, the first two digits represent red, the next two represent green, and the last two represent blue.

15.3 RGB Colors

RGB stands for Red, Green, and Blue. The RGB color function uses three values to define a color.

Each value ranges from 0 to 255. A value of 0 means no intensity, while 255 means maximum intensity.

Red rgb(255, 0, 0)
Blue rgb(0, 0, 255)
Green rgb(0, 255, 0)
Yellow rgb(255, 255, 0)
Orange rgb(255, 165, 0)
Purple rgb(128, 0, 128)

RGB Color Values

RGB Value Color Meaning
rgb(255, 0, 0) Red Maximum red
rgb(0, 255, 0) Green Maximum green
rgb(0, 0, 255) Blue Maximum blue
rgb(0, 0, 0) Black No color intensity
rgb(255, 255, 255) White Maximum intensity of all colors
Remember: RGB colors are based on mixing red, green, and blue light.

15.4 Grey Colors

Grey colors are created by using equal values of red, green, and blue. Different values create different shades of grey.

Black #000000
Dark Grey #404040
Grey #808080
Silver #C0C0C0
Light Grey #D3D3D3
White #FFFFFF

Different Shades of Grey

Color Name HEX Value Color Preview
Black #000000
Dim Grey #696969
Grey #808080
Dark Grey #A9A9A9
Silver #C0C0C0
Light Grey #D3D3D3
Gainsboro #DCDCDC
White Smoke #F5F5F5
White #FFFFFF
Note: Grey shades are formed by using the same intensity for red, green, and blue. Lower values create darker grey shades, while higher values create lighter shades.
