CHAPTER 07

HTML Graphics

Explore two ways to create graphics on a webpage: SVG for scalable vector shapes and Canvas for drawing areas.

This chapter displays visual demonstrations rather than source-code examples. SVG works directly in HTML. Canvas drawing normally requires JavaScript, so the Canvas section uses static SVG illustrations to stay within the HTML and CSS project requirements.

7.1 SVG Graphics

SVG stands for Scalable Vector Graphics. SVG images remain sharp when resized and are useful for icons, diagrams, logos, and illustrations.

7.1.1 SVG Rectangle

A rectangle uses a width and height. Rounded corners are optional.

7.1.2 SVG Circle

A circle uses a centre point and a radius.

7.1.3 SVG Ellipse

An ellipse has separate horizontal and vertical radii.

7.1.4 SVG Line

A line connects two points and uses a stroke for its appearance.

7.1.5 SVG Polyline

A polyline connects several points with straight segments without closing the shape.

7.1.6 SVG Polygon

A polygon connects multiple points and closes the shape automatically.

7.1.7 SVG Path

A path can draw complex lines and curves.

7.1.8 SVG Text

SVG text can be positioned and styled like other SVG shapes.

7.1.9 SVG Link

Click the book illustration to jump to the Canvas section.

7.1.10 SVG Stroke

Stroke properties control outline colour, thickness, line endings, and dash patterns.

  • 7.1.10.1 Stroke Color: changes the outline colour.
  • 7.1.10.2 Stroke Width: changes outline thickness.
  • 7.1.10.3 Stroke Ending: line caps can be butt, round, or square.
  • 7.1.10.4 Dash Stroke: creates dashed or dotted lines.

7.1.11 SVG Gradients

A gradient blends colours smoothly.

  • 7.1.11.1 Linear Gradient: colours blend along a straight direction.
  • 7.1.11.2 Radial Gradient: colours blend outward from a central point.

7.1.12 SVG Filters

SVG filters can add effects such as blur and drop shadows.

7.2 Canvas

The HTML canvas element provides a rectangular drawing area. JavaScript is normally used to draw on it. The following examples illustrate common Canvas results without using JavaScript.

These are static illustrations, not drawings generated by an actual Canvas context. JavaScript is needed to make Canvas draw text, lines, circles, rectangles, gradients, or images.

7.2.1 Draw Text

Canvas can display filled or outlined text.

7.2.2 Draw Lines

Lines can connect points to form patterns or diagrams.

7.2.3 Draw Circles

Circles can have different positions, radii, and colours.

7.2.4 Draw Rectangles

Rectangles may be filled or drawn as outlines.

7.2.5 Draw Gradients

Gradients create smooth transitions between colours.

  • 7.2.5.1 Linear Gradient: colour changes in a straight direction.
  • 7.2.5.2 Radial Gradient: colour changes outward from a centre point.

7.2.6 Draw Images

Canvas can display an image inside its drawing area. JavaScript normally places the image.

Chapter Summary

  • SVG creates scalable vector graphics directly in HTML.
  • SVG supports shapes, text, links, strokes, gradients, and filters.
  • Canvas provides a drawing area for graphics.
  • JavaScript is normally required to draw on Canvas.
