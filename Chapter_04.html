SEMANTIC HTML

Welcome to Semantic HTML!

Semantic HTML uses elements that describe the meaning of their content. This helps browsers, search engines and assistive technologies understand a webpage's structure.

4.1 Semantic Elements

Semantic elements explain what a piece of content represents instead of only describing how it looks.

Example

Book of the Week

This article introduces a featured book from the BIBLUNE collection.

The article element identifies a self-contained piece of content.

4.1.1 <blockquote>

The <blockquote> element marks a longer quotation taken from another source. The cite attribute can provide the source URL.

Live Example

“A book is a doorway to new ideas, places and possibilities.”

A blockquote is normally displayed as an indented quotation.

4.1.2 <address>

The <address> element provides contact information for the nearest article or the whole page.

Live Example

BIBLUNE Bookstore
24 Readers' Lane, Dhaka, Bangladesh
Email: hello@biblune.example

Use real contact details for a real website. The details above are examples.

4.1.3 <details> and <summary>

The <details> element creates a disclosure widget that users can open or close. Its first child should usually be a <summary> element that acts as the visible label.

Try It — Click the Summary

What makes BIBLUNE special?

BIBLUNE brings fiction, science and classic books together in one welcoming online bookstore.

How can I find a book?

Browse by category or use the search feature on the main bookstore page.

4.1.4 <figure> and <figcaption>

The <figure> element groups self-contained content, such as an image or illustration. The <figcaption> element provides its caption.

4.2 Semantic Layout Elements

Semantic layout elements describe the main regions of a webpage and make its structure easier to understand.

Layout Example

header — Logo and introductory content
nav — Fiction | Science | Classics
main — The page's primary content
section — A group of related books
article — One book review or story
aside — Related recommendations
footer — Copyright and contact links

Common Semantic Layout Tags

Purpose of Each Element
Element Purpose
<header> Introductory content or a page/section header
<nav> A group of navigation links
<main> The page's main content
<section> A themed group of related content
<article> Self-contained content, such as a review
<aside> Related or supplementary content
<footer> Footer information for a page or section

The example layout is shown inside the demo area; a real webpage should not nest a second main element inside the page's main content.

4.3 Semantic Formatting Elements

Semantic formatting elements give text meaning or emphasis. They are not just visual styling choices.

Quick Comparison

Important: Keep your account details private.

Emphasis: I really recommend this book.

4.3.1 <strong>

The <strong> element marks text as having strong importance, seriousness or urgency. Browsers commonly display it in bold.

Live Example

Important: Please check the book edition before placing your order.

Normal text: Orders are processed during business hours.

4.3.2 <em>

The <em> element adds stress emphasis to text. Browsers commonly display emphasized text in italics. You can nest it to express stronger emphasis.

Live Example

You should definitely read this novel.

I said, read the first chapter, not the last one.

Use <strong> for importance and <em> for stress emphasis. For appearance alone, CSS is usually more appropriate.
