HTML Advanced

Advanced HTML concepts, including Data URIs and the differences between block, inline, and inline-block elements.

8.1 Data URIs

A Data URI allows data to be included directly inside a webpage instead of loading it from a separate file.

It can be used for small images, icons, and other resources. The image data is written inside the source attribute.

8.2 Block Elements

Block elements usually begin on a new line. They take up the available width of their parent container by default.

Common block elements include div, p, h1, section, and article.

Inline elements do not usually start on a new line. They occupy only the space required by their content.

Inline-block elements appear next to one another like inline elements, but their width, height, padding, and margin can be controlled like block elements.

Chapter Summary

Data URIs allow resources to be embedded directly into a webpage.

Block elements usually start on a new line and occupy the available width.

Inline elements remain within the text flow and use only the space they need.

Inline-block elements appear beside one another while allowing width and height to be specified.
