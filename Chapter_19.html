19.1 CSS Position

The position property controls how an element is placed in a webpage. The top, right, bottom, and left properties can control its location, depending on the positioning method.

19.1.1 Static

Static is the default positioning method. The element follows the normal document flow.

Static Element

The element stays in its normal position.

19.1.2 Relative

Relative positioning moves an element from its normal position while keeping its original space in the layout.

Normal Element
Relative Element

19.1.3 Absolute

An absolutely positioned element is positioned relative to its nearest ancestor that establishes a positioning context.

19.1.4 Fixed

A fixed element is positioned relative to the viewport and usually stays in the same place when the page scrolls.

Sticky positioning behaves like normal positioning until the specified scroll position is reached.

19.3 CSS Z-Index

The z-index property controls the stacking order of positioned elements. Elements with a higher stacking level can appear in front of elements with a lower level within the same stacking context.

z-index: 1
z-index: 3
z-index: 2
Remember: z-index does not always compare elements globally. Stacking contexts can affect which element appears on top.
