21.1 CSS Variables

CSS variables store reusable values such as colors, spacing, and border radius. A variable can be reused in different parts of a stylesheet and updated from one place.

Remember: CSS custom properties are commonly declared with names beginning with two hyphens, such as --primary-color. The var() function uses their values.

21.3 CSS Counters
