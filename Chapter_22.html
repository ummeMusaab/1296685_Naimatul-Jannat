22.1 Responsive Web Design

Responsive Web Design (RWD) allows a website to adapt to different screen sizes, including mobile phones, tablets, laptops, and desktop computers.

Key idea: A responsive website adjusts its layout and content to provide a comfortable experience on different devices.

22.2 RWD Viewport

The viewport is the visible area of a web page. The viewport meta setting helps mobile browsers display a page at the device's actual width.

22.3 CSS Media

CSS media rules apply styles depending on the device, screen characteristics, or output type.

22.3.1 Media Types

Screen

For displays such as phones, tablets, laptops, and monitors.

Print

For printed pages and print previews.

All

Applies styles to all media types.

22.3.2 Media Queries

Media queries let a page use different styles when the viewport crosses a chosen breakpoint.

22.5 Mobile-First vs. Desktop-First

Mobile-first and desktop-first are two approaches to building responsive layouts. They differ in which screen size is designed for first.

22.5.1 Mobile-First

Phone
Tablet
Desktop

Start with a simple layout for small screens. Add or adjust styles as the screen gets wider.

Mobile-first card

22.5.2 Desktop-First

Desktop
Tablet
Phone

Start with a layout for large screens. Use media queries to adjust it for smaller screens.

Desktop-first card
Quick comparison: Mobile-first commonly adds styles with min-width media queries. Desktop-first commonly adjusts styles with max-width media queries.
