CHAPTER 09

HTML Events

Events are commonly handled using JavaScript to make webpages interactive.

9.1 Window Events

Window events occur when something happens to the browser window, such as loading a page or changing its size.

9.1.1 onload

The onload event occurs when the page and its required resources have finished loading.

Page Load Status

This message is displayed after the page has loaded.

Waiting for page load...

9.1.2 onresize

The onresize event occurs when the browser window is resized.

Resize the Browser

Change the width of the browser window to see the current dimensions.

Window size will appear here.

9.2 Form Events

Form events occur when users interact with input fields, text areas, and selection controls.

9.2.1 onfocus

The onfocus event occurs when an input field receives focus.

The input is not focused.

9.2.2 onblur

The onblur event occurs when an input field loses focus.

Waiting for the input to lose focus.

9.2.3 onchange

The onchange event occurs when the value of a form control changes and the change is committed.

Your selection will appear here.

9.2.4 oninput

The oninput event occurs whenever the value of an input field changes.

Your typed text will appear here.

9.3 Keyboard Events

Keyboard events occur when a user presses or releases a keyboard key.

9.3.1 onkeydown

The onkeydown event occurs when a keyboard key is pressed down.

No key pressed yet.

9.3.2 onkeyup

The onkeyup event occurs when a pressed keyboard key is released.

No key released yet.

9.3.3 onkeypress

The onkeypress event was used for character-producing key presses. It is deprecated in modern browsers.

Character information will appear here.

Modern applications generally use keydown or input instead of keypress.

9.4 Mouse Events

Mouse events occur when a user clicks, moves, presses, or releases a mouse button.

9.4.1 onclick

The onclick event occurs when an element is clicked.

Button has not been clicked.

9.4.2 ondblclick

The ondblclick event occurs when an element is double-clicked.

Double-click the button.

9.4.3 onmousemove

The onmousemove event occurs whenever the mouse pointer moves over an element.

Move Your Mouse Here

Move the pointer inside this area.

Mouse coordinates will appear here.

9.4.4 onmousedown and onmouseup

The onmousedown event occurs when a mouse button is pressed down. The onmouseup event occurs when the button is released.

Press and Release

Press and release your mouse button inside this area.

Waiting for mouse action.

9.4.5 onmouseover and onmouseout

The onmouseover event occurs when the pointer enters an element. The onmouseout event occurs when the pointer leaves it.

Move the Pointer Here

Move in and out of this area.

Pointer is outside the area.

9.5 Clipboard Events

Clipboard events occur when users copy, cut, or paste content.

Clipboard operations may be restricted by browser security rules. Use the browser's normal keyboard shortcuts or context menu.

9.5.1 oncopy

The oncopy event occurs when content is copied from an element.

Copy some text to see the event.

9.5.2 oncut

The oncut event occurs when selected content is cut from an editable element.

Cut some text to see the event.

9.5.3 onpaste

The onpaste event occurs when content is pasted into an editable element.

Paste some text to see the event.
