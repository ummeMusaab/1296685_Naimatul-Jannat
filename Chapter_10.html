10.3 Web Storage

Web Storage allows websites to store data in the user's browser.

The two main storage objects are localStorage and sessionStorage.

10.3.1 The localStorage Object

localStorage stores data without an expiration time. The data remains available until it is removed.

Saved book will appear here.

10.3.2 The sessionStorage Object

sessionStorage stores data for the duration of the current browser tab session.

10.4 Web Workers

Web Workers allow JavaScript to run in the background, separately from the main page.

They are useful for performing complex tasks without blocking the page's user interface.

10.4.1 Web Worker File

A Web Worker file contains the JavaScript code that runs in the background.

Example worker file: worker.js

The worker can perform calculations and send results back to the main page.

10.4.2 Web Worker Object

The Worker object allows a webpage to create and communicate with a Web Worker.

Worker output will appear here.

10.4.3 Web Workers and the DOM

Web Workers cannot directly access the DOM. They communicate with the main page using messages.

The main page receives the worker's message and updates the DOM.

Worker Communication:

Worker → Message → Main Page → DOM Update
