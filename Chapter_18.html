18.1 Display vs. Visibility

The display property controls how an element participates in the page layout. The visibility property controls whether the element can be seen.

18.1.1 Display

Block elements start on a new line, inline elements share a line, and inline-block elements can have a width and height while staying inline.

18.1.2 Visibility

With visibility: hidden, an element becomes invisible but still occupies its original space.

Visibility: Hidden
First item Hidden item Third item

The space for the hidden item is still reserved.

Remember: display: none removes the element from the layout. visibility: hidden hides it but keeps its space.

18.2 CSS Object-Fit

The object-fit property controls how an image or video fits inside its container when their dimensions do not match.

fill

Fills the box; may distort the image.

contain

Shows the entire image.

cover

Fills the box; may crop the image.

none

Uses the image's original size.

scale-down

Uses contain or none, whichever makes it smaller.

Tip: object-fit: cover is useful for book covers, product cards, and image galleries with equal-sized images.
