20.1 CSS Transitions

CSS transitions make changes in CSS properties happen gradually instead of instantly. Hover over the examples to see the effects.

20.1.1 Basic Transitions

Basic transitions smoothly change properties such as background color, text color, and position when an element is hovered over.

Hover over the button
What to notice: The button changes color and moves slightly upward instead of changing instantly.

20.1.2 Transition Delay

Transition-delay specifies how long the browser waits before beginning a transition.

Hover and wait briefly

This transition has a short delay, so the color and size change begins after you hover over the button.

20.1.3 Transition Timing Function

The transition-timing-function controls how the speed of a transition changes over time. Hover over each track to compare.

Ease-In
Ease-Out
Ease-In-Out
Remember: Linear keeps a constant speed. Ease-in starts slowly, while ease-out finishes slowly. Ease-in-out starts and ends slowly.

20.1.4 Shorthand Transition Property

The transition shorthand combines the property, duration, timing function, and optional delay in one declaration.

Hover over the card

The background, border shape, color, and size change together through a shorthand transition.

20.2 CSS Animations

CSS animations use keyframes to define how an element changes at different points in time. Unlike transitions, animations can run automatically without a hover action.

20.2.1 Two-step Keyframes

A simple animation can use from and to keyframes to describe its starting and ending states.

Multiple keyframes let an animation change its position, rotation, or color at several points during its timeline.
