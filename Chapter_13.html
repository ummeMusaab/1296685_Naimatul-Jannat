CHAPTER 13

CSS Cascading

Table of Contents

13.1 The Last Declaration Will Win 13.2 The More Specific Declaration 13.3 Inline Style 13.4 !important Declaration 13.5 Inheritance

13.1 Rule 1: The Last Declaration Will Win

When two declarations have the same importance and specificity, the declaration that comes later in the CSS wins.

The final color is purple.

Result: The second matching rule changes the text color to purple because it appears later.

13.2 Rule 2: The More Specific Declaration Will Win

When declarations compete at the same cascade priority, the selector with higher specificity wins.

A paragraph selected by its tag.

A paragraph selected by its class.

A paragraph selected by its ID.

Result: The ID selector has higher specificity than the class and type selectors.

13.3 Rule 3: Inline Style Is Preferred to Both Internal and External Styles

For ordinary author declarations, inline styles generally take precedence over matching internal and external stylesheet rules.

This text uses inline styling.

Result: The inline color is purple, even though a stylesheet rule sets the paragraph color to green.

13.4 Rule 4: The "!important" Declaration Is the Strongest Rule

The !important annotation gives a declaration higher priority within the cascade.

The important rule wins!

Result: The text is purple because its color declaration uses !important, overriding the ordinary rule.

Note: !important does not always beat every possible CSS declaration. Cascade origin, importance, layers, and other rules can affect the final result.

13.5 Inheritance

Inheritance allows some CSS properties to pass from a parent element to its child elements.

Parent Element

This child inherits the parent's text color and font size.

This child has its own text color.

Result: Text color and font size are inherited here, but the parent's border is not automatically inherited by its children.
