The <u> element marks text with an underline. Use it when the underline has a meaningful purpose, such as indicating a specially annotated word.

3.1.4 Strong Element

The <strong> element indicates that its content has strong importance, seriousness or urgency. Browsers generally display it in bold.

LIVE OUTPUT

Difference: <b> draws attention to text. <strong> communicates strong importance.

3.1.5 Emphasis Element

The <em> element adds stress emphasis to text. Browsers generally display it in italic.

Difference: <i> can indicate an alternate voice or mood, while <em> indicates emphasis.

3.2 HTML Style Attribute

The HTML style attribute applies inline CSS directly to an element. It can control text color, background color, font size, font family and alignment.

LIVE OUTPUT

Welcome to BIBLUNE!

Syntax:

style="property: value;"

A CSS declaration contains a property and a value, separated by a colon. Multiple declarations are separated by semicolons.

Text Color

The color property changes the color of the text.

Quick Reference Table

These are some commonly used CSS properties inside the style attribute.

Property Purpose Example
color Text color color: brown;
background-color Background color background-color: beige;
font-size Text size font-size: 20px;
font-family Typeface font-family: Arial;
text-align Text alignment text-align: center;
padding Inner spacing padding: 12px;
Important: Inline CSS applies to the element carrying the style attribute. For a large website like BIBLUNE, an internal or external stylesheet is usually easier to maintain.
