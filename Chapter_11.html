CHAPTER 11

Getting to Know CSS

A CSS rule consists of a selector and a declaration block.Each declaration contains a property and a value.

CSS makes webpages beautiful!

Selector: Selects the HTML element.

Property: Specifies what to style.

Value: Defines the style.

11.2 Comments in CSS

CSS comments are used to explain the code. They are ignored by the browser.

Comments in a Stylesheet

Comments help developers understand and organize their styles.

They do not change the appearance of the webpage.

11.3 CSS Units

CSS units define measurements such as width, height, margin, and font size.

Small measurement
Relative width
Fixed width: 250px

11.3.1 Absolute Lengths

Absolute units represent fixed measurements. They do not depend on the size of a parent element.

200px wide
5cm wide
2in wide

11.3.2 Relative Lengths

Relative units depend on another measurement, such as the font size of an element or its parent.

Width: 10em
Width: 10rem

11.3.2.1 em

The em unit is relative to the font size of the element's parent.

This text is 1em (20px).

This text is 1.5em (30px).

This text is 2em (40px).

11.3.2.2 rem

The rem unit is relative to the font size of the root HTML element.

This text is 1rem.

This text is 1.5rem.

This text is 2rem.
