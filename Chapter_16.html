Remember: The @font-face rule allows a website to load a custom font file. This visual sample uses an available font and does not require an external font file.
Property Purpose
color Changes text color.
text-decoration Adds or removes text decoration.
text-transform Changes letter case presentation.
white-space Controls spaces and line breaks.
text-overflow Controls how clipped text is indicated.
overflow-wrap / word-break Controls how long words wrap or break.
letter-spacing / word-spacing / line-height Controls text spacing.
text-align / text-indent Controls alignment and indentation.
Font properties Control typography.
@font-face Defines a custom font.
