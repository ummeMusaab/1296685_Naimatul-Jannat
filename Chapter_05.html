Welcome to Web Forms!

HTML forms collect information from readers, such as contact details, book preferences and order requests. Try the working examples below. This page uses HTML and CSS only; it does not display source code.

5.1 HTML Form Elements

Form elements let visitors enter information, choose options and submit responses.

5.1.1 <input> and <label>

A label describes an input field. Match the label's for value with the input's id.

5.1.2 <textarea>

Use a textarea when someone needs to write a longer message or review.

5.1.3 <select> and <option>

A select menu lets a visitor choose one item from a list.

5.1.4 <button>

A button can submit a form or perform another action when connected to suitable behavior.

These buttons are demonstrations. No JavaScript is used in this chapter.

5.1.5 <fieldset> and <legend>

Fieldset groups related controls, while legend gives the group a title.

Preferred Reading Format

5.1.6 <datalist>

Datalist suggests choices while still allowing a visitor to type another value.

5.3 HTML Input Attributes

Attributes adjust the default value, behavior and rules of form controls.

5.3.1 name

The name identifies a field when form data is submitted.

5.3.2 value

The value attribute sets a control's initial value.

5.3.3 placeholder

Placeholder shows a short hint inside an empty field.

5.3.4 readonly

A readonly field can be viewed and selected, but not edited.

5.3.5 disabled

A disabled field cannot be edited or submitted with the form.

5.3.6 size

The size attribute sets the visible width of a text input in characters.

5.3.7 multiple

The multiple attribute allows more than one file or email address to be selected or entered.

5.3.8 step

The step attribute sets the allowed intervals for a number input.

5.3.9 width and height

For an image input, width and height set the image's displayed dimensions.

5.3.10 autofocus

The autofocus attribute places the cursor in a field when the page loads. It is not used in this demo to avoid moving the visitor's cursor unexpectedly.

5.3.11 autocomplete

Autocomplete lets the browser suggest previously entered information.

5.4 Form Validation

HTML validation attributes help the browser check input before a form is submitted.

5.4.1 minlength

Minlength sets the minimum number of characters allowed.

5.4.2 maxlength

Maxlength sets the maximum number of characters allowed.

5.4.3 min and max

Min and max set the lowest and highest permitted values.

5.4.4 required

Required means the field must be filled in before the form can be submitted.

5.4.5 pattern

Pattern checks whether the entered text matches a specified format.

5.4.6 Styles for the Invalid Inputs

The :invalid pseudo-class can style a field when its value does not meet the input rules. Try entering an invalid email address.

A valid email field turns green; an invalid or empty required field turns red.
